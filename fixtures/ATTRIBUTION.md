# Open-Licensed Reference Fixtures

Only open-redistributable reference samples are included in `fixtures/`. CHGIS V6 files (EULA prohibits redistribution) and copyrighted PDFs are strictly excluded.

- `whg-place-sample.json`: **World Historical Gazetteer / GeoNames** (CC BY 4.0, GeoNames geographical database, Unxos GmbH, https://whgazetteer.org/entity/place:gn:745044/api).
- `cbdb-sources-inventory.csv`: Public bibliography inventory transcribed from https://cbdb.hsites.harvard.edu/cbdb-sources (contains zero CBDB person records).
